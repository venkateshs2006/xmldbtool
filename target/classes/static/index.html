Large File Mode (> 100 MB): Tag-Based Dummy Preview Data Simulated Dummy Records

The input XML file exceeds 100 MB. To prevent memory overhead and ensure instant UI response, the actual file was NOT read. The preview below displays 5 simulated dummy records generated dynamically based on your mapped tags.

NOTE: Large XML Preview & Processing Details
  • Zero File I/O: Because the source XML exceeds 100 MB, the preview engine completely skips reading or unmarshalling the physical file from disk or storage.
  • Tag-Based Dummy Data: Realistic sample data is synthesized dynamically using discovered XML tag and attribute names (e.g., IDs, SKUs, Statuses, Timestamps, Amounts).
  • Pipeline Validation: Data transformations (UPPER, LOWER, TRIM), table routing, and dynamic batch UPSERT SQL statements are tested against this synthetic dataset.
  • Full Batch Ingestion: In Step 6, the Spring Batch StAX chunk streaming engine will stream and insert 100% of the actual XML data into your target database tables without loading the full file into memory.
